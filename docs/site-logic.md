# Концепция сайта VS Code Messenger

## 1. Цель

Сайт имитирует визуальную оболочку VS Code по приложенному примеру, но не реализует функции редактора кода. Основной сценарий — простой мессенджер для двух участников: один пользователь пишет в левом окне, собеседник — в правом.

Регистрация и авторизация не требуются. Сайт открывается сразу в рабочем пространстве.

## 2. Макет интерфейса

### Верхняя панель

- Тёмная панель в стиле VS Code.
- Декоративные кнопки окна слева.
- Центральное поле поиска/заголовка.
- Декоративные кнопки навигации и управления раскладкой справа.
- Элементы панели не запускают настоящие функции VS Code.

### Левая вертикальная панель

- Узкая панель с иконками для поддержания визуального сходства.
- Основное рабочее пространство открывается по иконке чата.
- Активная иконка подсвечивается.

### Центральное рабочее пространство

Рабочая область разделена вертикальным разделителем на два одинаковых окна:

- Левое окно — «Вы».
- Правое окно — «Собеседник».

Каждое окно содержит вкладку с именем участника, область сообщений, прокрутку, поле ввода, кнопку прикрепления файла и кнопку отправки. На узких экранах окна переходят в вертикальную раскладку или переключаются вкладками.

## 3. Логика сообщений

Каждое окно имеет собственное поле ввода и кнопку отправки.

1. Пользователь вводит текст и нажимает Enter или кнопку отправки.
2. Сообщение появляется в ленте соответствующего окна с меткой времени.
3. Новые сообщения добавляются в конец, прокрутка переходит к последнему сообщению.
4. Пустые сообщения не отправляются.
5. Shift+Enter создаёт новую строку, Enter отправляет сообщение.

На первом этапе обмен происходит в одном браузере и на одной странице, чтобы два окна имитировали диалог.

## 4. Отправка файлов

Разрешённые расширения: `.py` и `.cpp`.

1. Пользователь нажимает скрепку в нужном окне.
2. Открывается стандартный выбор файла.
3. Клиентская проверка разрешает только `.py` и `.cpp`.
4. При недопустимом расширении показывается ошибка.
5. В ленте появляется карточка с именем и размером файла.
6. Файл можно скачать из карточки.

На первом этапе файл хранится в памяти браузера через File/Object URL и исчезает после перезагрузки.

## 5. Состояния интерфейса

Нужны состояния пустого чата, текстового сообщения, карточки файла, ошибки валидации, отправки, отключённого поля, длинной переписки и мобильной раскладки.

## 6. Визуальный стиль

Чёрно-серая палитра VS Code, почти чёрный фон, тёмно-серые панели, тонкие разделители, синий акцент, умеренные скругления, системный шрифт интерфейса и моноширинный шрифт для сообщений и имён файлов.

## 7. Модель данных

```js
{
  id: string,
  author: "me" | "companion",
  type: "text" | "file",
  text: string | null,
  file: { name: string, extension: ".py" | ".cpp", size: number, url: string } | null,
  createdAt: string
}
```

## 8. Границы первой версии

Без регистрации, серверной синхронизации между браузерами, редактирования и запуска кода, сохранения после закрытия страницы, групп, звонков и нескольких собеседников.

## 9. Возможное развитие

WebSocket для обмена между устройствами, комнаты по короткой ссылке, серверное хранение, предпросмотр кода, темы, очистка и экспорт переписки.

## 10. Критерии готовности

Страница открывается без регистрации, визуально соответствует примеру, содержит два окна, отправляет текст по Enter и кнопке, поддерживает Shift+Enter, принимает только `.py` и `.cpp`, показывает и скачивает файлы, объясняет ошибки и работает на узком экране.
